# دمج Claude مع مهامي

## 1) تثبيت الخادم
افتح مجلد الخادم ثم:

```bash
npm install
```

## 2) المفتاح السري
انسخ `.env.example` إلى `.env`، ثم ضع مفتاح Anthropic داخل:

`ANTHROPIC_API_KEY=...`

لا تضع هذا المفتاح داخل `index.html` ولا GitHub Pages.

ضع `SESSION_SECRET` عشوائيًا طويلًا (32 حرفًا أو أكثر).

## 3) تشغيل الخادم

```bash
npm start
```

سيعمل افتراضيًا على:

`http://localhost:3000`

وللفحص:

`GET /api/health`

## 4) ربط صفحة مهامي بالخادم
الملف `index.html` يستخدم افتراضيًا:

`http://localhost:3000`

وعند النشر يمكن وضع:

```html
<script>window.MAHAMI_API_BASE_URL='https://YOUR-SERVER-DOMAIN';</script>
```

قبل سكربت التطبيق الرئيسي.

## 5) الملفات التي يدعمها المساعد
- صورة: PNG / JPEG / GIF / WebP
- PDF حتى 8MB

المساعد يقرأ المرفق على السيرفر ويرسله إلى Claude، والمفتاح يبقى في السيرفر.

## 6) الأفعال
المساعد يستطيع طلب:
- إضافة مهمة
- عرض مهام اليوم وبيانات الإحصائيات
- إكمال مهمة
- إضافة ملاحظة
- تسجيل مصروف
- حذف مهمة أو ملاحظة بعد تأكيد الطالب

البيانات المستخدمة هي بيانات الطالب الحالية التي يرسلها التطبيق، ولا يخزن السيرفر بيانات التطبيق نفسها.

## 7) وضع التركيز وتطوير العقارات
واجهة وضع التركيز أصبحت نظام بناء متدرجًا داخل التطبيق:
- 5 مشاريع مستقلة: بيت عصري، فيلا فاخرة، قصر ملكي، استراحة ريفية، مبنى تجاري.
- لكل مشروع تقدمه الخاص المحفوظ في بيانات مهامي.
- 7 مستويات متدرجة: الأساس والأرض، بيت صغير/كوخ، شقة/مبنى سكني، عمارة كاملة، فيلا فاخرة، قصر، قلعة حصينة.
- كل جلسة تركيز مكتملة تضيف دقائق إلى المشروع المحدد وتحدّث المستوى والمشهد تلقائيًا.
- المشهد ثلاثي الأبعاد قابل للدوران 360 درجة بالسحب، مع دوران تلقائي وإضاءة وظلال.
- أزيلت عناصر المواعيد القديمة من نافذة التركيز وأصبحت النافذة مخصصة للبناء والتقدم.

حدود الترقية الحالية للمستويات هي: 0، 60، 180، 360، 600، 900، 1200 دقيقة تركيز تراكمية لكل مشروع.


## التحديثات الأخيرة

- **الإشعارات الحقيقية:** يوجد `sw.js` + `js/notifications.js` لاستخدام Web Notifications، مع طلب الإذن من تفاعل المستخدم، وإظهار إشعار عند انتهاء جلسة التركيز أو انتقال العقار لمستوى جديد. على الجوال، الإشعارات المستمرة تعتمد على Service Worker ودعم المتصفح.
- **أسماء المستخدمين الفريدة:** `js/profile.js` يمنع التكرار محليًا، والسيرفر يفرض التفرد عالميًا عبر `/api/usernames/register` ويحفظه في `usernames.json`.
- **التصنيف العالمي:** `js/leaderboard.js` وواجهات `/api/leaderboard` تحفظ إجمالي دقائق التركيز لكل حساب وتعرض لوحة التصنيف. النسخة الحالية تعتمد على بيانات يرسلها العميل، لذلك ليست نظامًا تنافسيًا مقاومًا للغش حتى تضيف مصادقة حقيقية وتوقيت جلسات على السيرفر.
- **الدفع:** `js/payments.js` و`/api/billing/create-checkout-session` يجهزان Stripe Checkout مع بقاء المفاتيح السرية في السيرفر. Stripe Checkout/Payment Element يمكنه إظهار Apple Pay/Google Pay عندما يكونان مؤهلين ومفعلين في حساب Stripe.
- **تنظيم الملفات:** تم فصل CSS إلى `css/mahami.css`، والنواة القديمة إلى `js/app.js`، ووحدات الإشعارات والملف الشخصي والتركيز والتصنيف والدفع والإعدادات إلى ملفات مستقلة.

### التشغيل
1. `npm install`
2. انسخ `.env.example` إلى `.env`.
3. ضع `ANTHROPIC_API_KEY` و`SESSION_SECRET` كما في التعليمات السابقة.
4. لفرض التفرد عالميًا وتشغيل التصنيف، اترك السيرفر متصلًا أثناء الاستخدام.
5. للدفع، أضف `STRIPE_SECRET_KEY` و`STRIPE_PRICE_PRO` ثم شغّل `npm start`.


## واجهة مستقرة — قسم مهامي
تمت إعادة `index.html` إلى نسخة الواجهة المستقرة السابقة قبل آخر إعادة هيكلة للملفات. جميع تعديلات التصنيف الجديدة معزولة داخل نافذة `وضع التركيز` وقسم العقارات، ولا يوجد CSS عام جديد يغيّر باقي الأقسام.


## إعدادات مهامي الجديدة
- الملف الشخصي: اسم مستخدم فريد، صورة شخصية، وخلفية مخصصة.
- التركيز والبناء: Wake Lock، بداية اليوم، طريقة عرض ساعات التركيز، المشروع الافتراضي، والدوران التلقائي.
- الخصوصية الاجتماعية: الظهور في التصنيف العالمي وطلبات الصداقة والمتابعة.
- الإشعارات والصوت: إشعارات المتصفح، نمط التنبيهات، والمؤثرات الصوتية.
- المظهر: اللون الأساسي والثانوي واللغة الحالية.
- كل عناصر هذه الإعدادات موجودة داخل صفحة الإعدادات فقط.

## تفاعلات الصوت
- تمت إضافة `playSound(type)` للأصوات: `click`, `toggle`, `success`.
- الأصوات تحترم إعداد `المؤثرات الصوتية` الموجود في صفحة الإعدادات.
- أزرار الحفظ تستخدم صوت النجاح، وباقي الأزرار تستخدم صوت النقرة.
- مفاتيح التبديل تستخدم صوت التفعيل وتبقى حالات عناصر checkbox محفوظة في LocalStorage عند وجودها.
- لم تتم إضافة `alert` جديد للحفظ حتى لا تتداخل رسائل النظام الحالية مع تجربة المستخدم.

## آخر تحديث: تفعيل الوظائف الحقيقية

تم إصلاح عدة خيارات كانت تحفظ الإعداد فقط بدون أثر كامل:

- **بداية اليوم** أصبحت تؤثر فعليًا على تعريف "اليوم" داخل المهام والتاريخ بعد تغييرها.
- **الاجتماعي** أصبح مربوطًا بالسيرفر: إرسال طلب صداقة، قبول/رفض الطلب، والمتابعة، مع احترام إعدادات استقبال الطلبات والمتابعة.
- **الظهور في التصنيف** يُحترم على السيرفر، وعند إخفائه تتم إزالة السجل من التصنيف.
- **نمط التنبيهات** (هادئ/تفصيلي/مختصر) يغيّر نص الإشعار الحقيقي.
- تمت إضافة زر **تجربة إشعار وصوت** داخل الإعدادات فقط.
- أصوات النقر/التبديل/النجاح لها نغمة احتياطية محلية عبر Web Audio عند فشل تحميل الصوت الخارجي.
- تم ربط إكمال جلسة التركيز بتحديث التصنيف بعد نهاية الجلسة.

### بيانات إضافية على السيرفر

يتم إنشاء ملفي `social.json` و`social-prefs.json` تلقائيًا لحفظ العلاقات وتفضيلات الخصوصية.
